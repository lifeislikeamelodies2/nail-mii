# Nail Mii

10円玉（直径23.5 mm）または100円玉（直径22.6 mm）を基準に、iPhone / Android のカメラや写真から爪の横幅を測る静的Webアプリです。

## 公開先

GitHub Pages 有効化後： https://lifeislikeamelodies2.github.io/nail-mii/

## 使い方

1. 手と10円玉または100円玉を、できるだけ同じ高さに置き、真上から撮影します。
2. コインの種類を選び、写真上で硬貨の外周両端を指定して直径を校正します。
3. 爪の横幅の左右両端を選んで測定します。点はドラッグ・拡大表示で調整できます。
4. 左右10本の結果を端末内に保存し、購入先のサイズ表に合わせて候補号数を確認できます。
5. 計測結果は画像保存・テキストコピーができます。

## ご注意

- 爪とコインの位置を**手動で2点指定する半自動計測**です。AIによる輪郭の自動検出はありません。
- 真上からの**直線幅**と、爪のカーブに沿った幅は異なります。ネイルチップ購入前にメーカーのサイズ表とサンプルチップでご確認ください。
- 初期の号数表はサンプルです。購入先のサイズ表に置き換えてください。
- 写真はブラウザ内で処理され、アップロードされません。計測幅・サイズ表は利用端末の localStorage に保存され、別端末と同期しません。
- カメラは HTTPS の GitHub Pages で利用してください。カメラが利用できない場合は写真選択もできます。

## GitHub Pages公開設定

GitHubのリポジトリ画面で **Settings → Pages → Build and deployment** に進み、**Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** を設定して Save してください。

HTML/CSS/JavaScriptのみで動作し、サーバー・ログインは不要です。アイコンにはSVGを使用します。
